## 🚀 Featured Projects

### 🎬 CineSphere
> Social network for cinema lovers — think Letterboxd, built from scratch.

A full-stack social platform where users can discover movies, write reviews, manage their watchlist, follow other cinephiles, and track their activity. Built as a team final project at Henry bootcamp.

**Tech:** Next.js · TypeScript · Tailwind CSS · Zustand · NestJS · PostgreSQL · TypeORM · JWT · Cloudinary

**Highlights:**
- JWT authentication with Google OAuth integration
- Full review system with ratings, likes and comments
- Social feed showing activity from followed users
- User profile with dynamic tabs: activity, reviews, watchlist and stats
- Protected routes and role-based access (user / admin)
- Image uploads via Cloudinary
- Responsive design across all devices

[View Repository](https://frontend-xi-seven-xl5nfdr4tz.vercel.app/) <!-- actualiza el link si es diferente -->

### 🛒 Nexus Shop
> Tech e-commerce platform built as a full-stack individual project.

A complete e-commerce application with product catalog, authentication, shopping cart, and order management. Designed with a clean, modern UI inspired by Apple and Xiaomi storefronts.

**Tech:** Next.js 15 · Tailwind CSS · Express · TypeORM · PostgreSQL · JWT

**Highlights:**
- JWT-based authentication with protected routes
- Shopping cart with quantity management and per-user persistence
- Discount and on-sale product system
- Fully responsive, mobile-first design
